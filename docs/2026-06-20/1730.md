# pnpm

- @repo/shared从来没有发布到 npm.

  pnpm 是如何发现这个 @repo/shared 包的?答案藏在 node_modules/@repo 里

- pnpm-workspaces.yaml

```json
packages:
  - "apps/_"
  - "packages/_"

```

pnpm-workspaces.yaml 的 apps/_ 和 packages/_ 是通配符.pnpminstall时 pnpm据此
扫描处所有本地包,建一张[包名+目录]的表

- apps/web/package.json

```json
"dependencies": {
  "@repo/shared": "workspace:*",
  "@repo/ui": "workspace:*",
  "react": "^18.3.0",
  "react-dom": "^18.3.0"
},
```

workspace: _ 是指`别去 npm下载,用本地的`暗号
当pnpm 在某个包的 packagejson看到 `"@repo/ui": "workspace:_"`,它是不会去互联网下载的
而是在 node_modules 里创建一个`符号链接(软链)`指回`package/ui`

这是 `pacakges/ui/package.json`的配置

```json
{
  "name": "@repo/ui", // 这里把这个包命名为`repo/ui`
  "version": "0.0.0",
  "private": true,
  "type": "module",
  "main": "./dist/index.js",
  "types": "./dist/index.d.ts",
  "exports": {
    ".": "./dist/index.js"
  },
  "scripts": {
    "build": "tsc",
    "lint": "tsc --noEmit"
  },
  "peerDependencies": {
    "react": "^18.3.0",
    "react-dom": "^18.3.0"
  },
  "devDependencies": {
    "@types/react": "^18.3.0",
    "@types/react-dom": "^18.3.0",
    "typescript": "^5.5.0"
  }
}
```

- 所以,monorepo里跨包 import的本质= 文件系统级的软链接,不是网络下载.
  这点通,接下来全通.
