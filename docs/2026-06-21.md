# 06-21

- 回忆 packages/ui/package.json 里 react 是 peerDependency 而非普通 dependency。这是设计 UI 库的标准做法:ui 不自己捆绑一份
  react,而是"借用宿主(web)的 react"。否则 web 和 ui 各装一份 react,会出现臭名昭著的 "Invalid hook call / 两个 React 实例"
  错误。peerDependency = "我需要它,但请由用我的人提供"。

```json
{
  "name": "@repo/ui",
  "version": "0.0.0",
  "private": true,
  "type": "module",
  "main": "./dist/index.js",
  "types": "./dist/index.d.ts",
  "exports": {
    ".": "./dist/index.js"
  },
  "scripts": {
    "build": "tsc",
    "lint": "tsc --noEmit"
  },
  "peerDependencies": {
    // 这里的意思是:我需要用到这个,但不是我自己下载,而是由用我的人下载,我去用你的即可
    "react": "^18.3.0",
    "react-dom": "^18.3.0"
  },
  "devDependencies": {
    "@types/react": "^18.3.0",
    "@types/react-dom": "^18.3.0",
    "typescript": "^5.5.0"
  }
}
```
